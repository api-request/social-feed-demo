# APIRequest.dev Social Feed Demo

A simple social feed demo built with plain HTML and JavaScript using the **APIRequest.dev Social Media API**.

This project was used in the APIRequest.dev demo/tutorial to show how you can build a frontend against a ready-to-use backend API without setting up your own server or database.

## What's included

The project contains only:

* HTML
* JavaScript

No framework, npm packages, build tools, or backend setup are required.

## Features

The demo shows how to work with the Social Media API to build common social app functionality, such as:

* Loading a social feed
* Working with users and posts
* Authentication
* Sending requests with JavaScript
* Interacting with API data from the frontend

## Running the project

Clone the repository:

```bash
git clone <repository-url>
```

Then open the project folder and run the HTML file in your browser.

For the best experience, you can also use a simple local development server such as VS Code Live Server.

## API

This project uses the **APIRequest.dev Social Media API**.

APIRequest.dev provides ready-to-use APIs for frontend development, learning, prototyping, and portfolio projects.

Visit:

https://apirequest.dev/documentation#social-media-api

## About APIRequest.dev

APIRequest.dev lets you start building against realistic APIs without first creating and deploying a backend.

Choose an existing API, make requests from your application, and focus on building the frontend.
